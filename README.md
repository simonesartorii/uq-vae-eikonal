# uq-vae-eikonal

Solving inverse problems for the Eikonal model via Physics-Informed Neural Networks (PINNs) and Uncertainty Quantification Variational Autoencoders (UQ-VAE).

## Structure

- `data` – input data
- `models` – trained models
- `notebooks` – Jupyter notebooks
- `results` – outputs and figures
- `scripts` – training and evaluation scripts
- `src` – source code

## Requirements

Python 3, NumPy, Matplotlib, Fenics, Tensorflow, Tensorflow Probability, .

## Usage

```bash
git clone https://github.com/simonesartorii/uq-vae-eikonal.git
cd uq-vae-eikonal
```

Then run the notebooks in `notebooks/` or the scripts in `scripts/`.
